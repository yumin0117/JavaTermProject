# 실행과 확인 순서

1. `pom.xml`을 IntelliJ에서 열고 Java 17을 설정한다. 작업 디렉터리는 JavaTermProject다.
2. 빈 스키마에서만 01 원본 SQL을 실행한다. 기존 DB에서는 원본 SQL을 재실행하지 않는다. 02 → 06 → 08 → 09를 SQL Developer F5로 실행한다.
3. `config/db.properties`를 설정하거나 앱의 연결 설정을 사용한다. 실제 접속 정보는 Git에 올리지 않는다.
4. `App.main()` 또는 빌드 후 `run.bat` 실행. 로그인 없이 TOP100 홈과 100곡 연결 상태를 확인한다.
5. 전체 곡에서 가수·곡명·앨범을 검색하고 TOP 10/50 필터를 확인한다. 갱신 버튼은 공개 차트를 검증한 뒤 DB에 저장한다.
6. 새 플레이리스트를 만들고 제목·설명·공개 여부를 수정한다. 곡 3개를 담고 상세 화면에서 순서 이동·제거·좋아요·취소·삭제를 확인한다.
7. 음원 없는 곡은 ‘정보’로 표시된다. 더블클릭하면 곡 페이지 열기 또는 보유 MP3 연결을 선택한다. 해당 곡의 사용 권한이 있는 MP3를 연결한다.
8. 무료 재생은 60초에서 정지하고 이동도 60초까지 제한된다. 모의 Plus 구매 시 DB 내역과 유효기간을 조회하여 전체 길이 재생한다. 실제 청구액은 0원이다. 취소 후 무료 상태로 돌아온다.
9. `mvn -Poracle-test package`는 실제 Oracle 검증까지 수행한다. 테스트가 만든 임시 데이터만 정리한다. UI 캡처 도구는 `kr.ac.yumin.playlist.CaptureScreens`다.

모의 Plus는 멜론 스트리밍 권한을 제공하지 않는다. 차트 메타데이터와 실제 음원은 별개다.
