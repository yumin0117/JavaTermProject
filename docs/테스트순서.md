# 실행과 확인 순서

1. IntelliJ에서 pom.xml을 열고 Java 17과 JavaTermProject 작업 디렉터리를 지정한다.
2. 빈 스키마에서만 SQL 01과 COMMIT을 실행한다. 이어서 02 → 06 → 08 → 09 → 10 → 11 → 13 → 14를 SQL Developer F5로 실행한다.
3. config/db.properties 접속 정보를 설정하고 App.main() 또는 run.bat을 실행한다.
4. 로그인 없이 홈이 열리고 TOP100·곡 가져오기·연결 설정·좋아요한 목록 메뉴가 없는지 확인한다.
5. 제목·가수·앨범 검색, 전체/즐겨찾기 필터를 확인한다. 재생 확인된 곡과 미연결/재생 제한 곡을 구분한다.
6. NEON의 영상 버튼을 누른다. 새 창 없이 앱 중앙에서 뮤비가 나오고 오른쪽 추천 목록·댓글·구독 영역이 없는지 확인한다.
7. 무료 등급은 60초에서 멈추고 다시 재생해도 60초 이후를 계속 들을 수 없어야 한다. 끄는 체크박스가 없어야 한다.
8. Plus 이용권에서 모의 결제한다. 실제 청구는 0원이고 Oracle 주문·만료 시각이 저장된다. 같은 뮤비를 61초 이후로 재생하고 모의 결제 취소 후 다시 제한되는지 확인한다.
9. 재생 위치·음량·이전/다음·재생/일시정지를 확인한다. 다른 메뉴로 이동하면 영상이 멈춰야 한다.
10. NEON 커버를 클릭하여 발매일 2026.10.13과 작사/작곡 Dem Jointz·유영진을 확인한다. 별을 저장/해제하고 재실행 후 DB 상태를 확인한다.
11. 목록을 생성·수정하고 3곡을 담아 순서를 바꾼다. 곡 제거·공개 목록 좋아요/취소·목록 삭제를 확인한다.
12. mvn -Poracle-test package로 20개 검사를 수행한다. 실제 네트워크 영상 검사는 OnlineVideoSmoke에서 임시 회원으로 모의 구매·취소까지 실행하며 그 회원만 정리한다.

2026-11-26 영상 확인 결과: 메타데이터 137곡, 실제 임베드 재생 119곡, 미연결 13곡, 연결되었으나 임베드 제한/미확인 18곡. 영상 게시자의 설정과 지역에 따라 결과가 달라질 수 있다. 표준 플레이어 광고와 표시를 제거하지 않는다.
