# 실제 음악과 음원 출처

음원은 [Musopen - The Complete Chopin Collection](https://archive.org/details/musopen-chopin)의 실제 녹음이다.
해당 컬렉션은 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)으로 공개되어 있다.
작곡가는 Frédéric Chopin이며, 녹음자 개인 이름이 확인되지 않아 임의로 기재하지 않는다.
음원 파일은 음량·속도·구간을 편집하지 않은 원본 MP3이다. 카드 커버는 앱에서 그린 별도 그래픽이다.
모의 결제는 앱 기능 시연용으로 실제 음원의 구매나 저작권료를 청구하는 서비스가 아니다.
원본 파일명·다운로드 URL·SHA-256은 audio-sources.json에 기록했다.
